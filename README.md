# LAN-chat
A simple P2P CLI tool that enables chatting and file sending across LAN network

## Functionality (proposed idea)
### Scan network
LAN network will be scanned for other devices using this app
### Send Messages and Files
LAN-chat will enable to transfer messages or files between files. (*Possible but not guaranteed compression of larger files*)
### Set custom nickname
One will be able to set custom nickname so it is easier to recognise devices on network
